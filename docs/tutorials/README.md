# Tutorials

Worked scenarios you can run end to end. Each one loads its own sample data, builds something real,
and says what to look at afterwards. They assume the stack from the
[online quickstart](../quickstart-online.md) is up.

| Tutorial | What you build | Time |
|---|---|---|
| [Assembling one document out of many tables](assembling-a-document-with-nest.md) | A live customer document assembled from nine relational tables with a `nest` transform, kept current by change data capture. Includes the rule that decides which document shapes a nest can express. | ~30 min |

Sample data ships beside the tutorial that uses it ([`shop.sql`](shop.sql)) and is generated
deterministically, so the numbers quoted in the text are the numbers you will see.
